# Проверки перед публикацией

Проверки выполнены 14 октября 2026 года локально, без подключения к игровой ВМ и без изменения её процессов. Результаты не заменяют пользовательскую проверку остальных игровых механик.

## Результаты

- **Python:** compileall скриптов и тестов прошёл без ошибок.
- **Offline suite:** шесть unittest-проверок прошли: симметрия/состояние GameCrypt, Auth checksum/padding, Lineage2Ver411 roundtrip, контракт классического хеша, запрет неявного login probe и отсутствие живых паролей в шаблонах.
- **Базовый PE-builder:** из приватного оригинала получен точный SHA256 `46BDA8BEEE36F99B25D8EA5EFB315323A92CE1A0A134F06CB4C9B1C38027C1F1`. Встроенная эмуляция проверила изменение только выбранных opcode, регистры и баланс стека.
- **Экспериментальный PE-builder:** воспроизведён SHA256 `10124FF7F8425B2709E785A622125C88B269DEED6F19054463695DAB98C31286`. Результат остался локальным и не установлен на сервер.
- **Клиентский builder:** воспроизведён SHA256 ранее переданного ZIP `c6048244e43ba1085d6788b1e3b9930bf380dbf7b425a1a180ca67cb65385032`. Единственный изменённый элемент исходного архива: `system/l2.ini`.
- **Пакетный валидатор:** приватные CharSelected259/UserInfo440 разобраны по строкам форматов соответствующего Engine.dll до точной границы тела.
- **Состав публикации:** оригинальные/генерируемые EXE/DLL, клиентские архивы, SQL backups, captures и локальные секреты исключены.

## Что ещё не проверено

Новые публичные PowerShell-обёртки, санитарные шаблоны и helper установки supervisor не применялись на работающей SABINE. В Linux-среде публикации нет Windows PowerShell runtime; их новую версию нужно отдельно проверить на восстановленной остановленной ВМ.

Полная загрузка после reboot, корректное сохранение после принудительной остановки, бой, квесты, нагрузка, watchdog и независимый аудит сторонних бинарников не подтверждены. Успешный GUI-вход относится к установленной базовой конфигурации, а не к экспериментальному NPC-tail.
