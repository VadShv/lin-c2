# Исторический стенд Imani

Этот файл сохраняет выводы ранней итерации до переноса на SABINE и не является текущей инструкцией. Рабочий адрес, WorldId, клиентская совместимость и окончательное подтверждение мира находятся в [STATUS.md](STATUS.md).

## Сохранённые наблюдения

- **Окружение:** ранние работы велись на Windows-стенде Imani с адресом `136.234.76.201`; этот адрес больше не используется текущим клиентским комплектом.
- **Диск:** диагностические ProcMon-трассы занимали значительную часть диска; временные трассы были очищены, служебные файлы вынесены из корня C:\.
- **ODBC LogD:** исправлен поиск относительного File DSN `linworld` через 32-битный DefaultDSNDir.
- **Контекст запуска:** PsExec/session 1 на исследованном стенде приводил к SQL_ERROR; supervisor/session 0 позволил пройти ODBC и запустить цепочку.
- **INI:** удаление кавычек вокруг адресов в L2Server/NPC устранило проблемы подключения к CacheD.
- **Ранние настройки мира:** использовался Bartz с id=3; на SABINE окончательная конфигурация имеет id=1 и не должна наследовать это значение.

## Что ранняя итерация не подтверждала

Запуск процессов не подтверждал вход настоящего C2-клиента. Позднее выявлены несовместимый формат списка миров, фактические протоколы 481/485 и дополнительные поля пакетов после выбора персонажа.

Старые оценки времени старта и рекомендации по RAM не переносятся сюда как результаты текущего теста. Реквизиты тестовых аккаунтов и runtime-строки подключения из исторического журнала намеренно исключены из публичной версии.
