# Архитектура рабочего стенда

Нативные Windows-демоны взаимодействуют через локальные TCP-соединения и SQL Server. Ниже описана исследованная тестовая конфигурация, а не универсальная архитектура любой сборки Lineage 2.

```text
C2 client
  ├─ TCP2106 ─ L2AuthD ─ SQL lin2db
  └─ TCP7777 ─ L2Server ─ Cached ─ SQL world/user/comm
                   │         │
                   │         └─ TCP2008 ─ L2NPC
                   └─ TCP2002 ────────── L2NPC

L2LogD: TCP3999, SQL lin2log/lin2report
L2Server -> AuthD TCP2104; AuthD internal TCP2108
L2Supervisor (session 0): start order, dialogs, administrative script queue
```

| Процесс | Порты / связи | Роль |
|---|---|---|
| L2LogD | 3999 | Логи и BBS/report-подключения |
| L2AuthD | 2106, 2104, 2108 | Логин, список миров, ключи перехода |
| Cached | 2006, 2008, 2009 | Доступ мира и NPC к игровым БД |
| L2Server | 7777, 2002 | Клиенты, состояние мира, связь с NPC |
| L2NPC | Подключения к Cache и world | AI и серверные NPC |

PetitionD в рабочую обязательную цепочку не включён. Само наличие процессов/слушателей не гарантирует правильную авторизацию, пакетный формат или сохранение прогресса.

## Hook совместимости

Исходный L2Server483 имеет base `0x400000`; hook расположен на VA `0x4DFBCB`, исходные инструкции `83 c4 10 85 c0`. Новая секция `.c2fix` исполняет исходную очистку стека и добавляет поля перед дальнейшим шифрованием/отправкой.

В исследованном месте EAX содержит длину тела, ESI указывает на IOBuffer, тело начинается с `+0x12`. Генератор проверяет SHA исходного файла, base, отсутствие ожидаемого ASLR-флага, байты hook и инструкции GetProtocolVersion.

Базовый вариант меняет только opcode0x15/0x04; время мира в CharSelected переносится, а не обнуляется. ECX, EDX, ESI и требуемый баланс стека проверяются в эмуляции; другие исследованные opcode проходят без изменения.

Это точечная совместимость конкретного бинарника с конкретным клиентом, а не универсальная реконструкция сетевого протокола. Форматы дополнительных игровых пакетов и механики требуют отдельной проверки.
